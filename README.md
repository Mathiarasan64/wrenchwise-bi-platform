# wrenchwise-bi-platform
Enterprise Business Intelligence Platform for Wrench Wise Operations with live Zoho Sheet analytics, executive dashboards, and operational insights

## Overview

Wrench Wise Business Intelligence Platform (WW-BI) is an internal analytics platform developed for Wrench Wise Operations.

The platform provides real-time business intelligence using a live Zoho Sheet as the primary data source.

## Features

- Executive Dashboard
- Revenue Analytics
- Learner Analytics
- Sales Executive Dashboard
- Operations MIS
- Reports & Export
- Business Insights

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- Recharts
- PapaParse
